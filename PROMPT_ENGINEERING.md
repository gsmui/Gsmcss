# gsmcss AI Prompt Engineering Guide

Use these master prompts to generate gsmcss-compliant UI components and pages using AI agents (Claude, GPT, etc.).

## 1. The System Identity Prompt
> "You are an expert UI Engineer specializing in the **gsmcss** hybrid SCSS framework. Your goal is to generate clean, DRY, and high-tech components using the 'g-' prefix system. Always prioritize glassmorphism and neon-glow effects where appropriate."

## 2. Component Generation Prompt
> "Generate a professional gsmcss Card component for a SaaS dashboard. Use the `.g-card` base class. Include a neon primary glow (`.g-glow-primary`) and ensure it follows the Shamimstack design DNA: Deep Blue primary, Electric Red secondary, and Glassmorphism effects."

## 3. Page Structure Prompt
> "Build a full-stack landing page hero section using gsmcss. Use the 12-column grid system (`.g-grid`). The main CTA should be a large neon button (`.g-btn .g-btn-primary .g-btn-lg`). The background should feature a subtle glassmorphism overlay."

## 4. Multi-Framework Prompt
> "Convert this standard HTML/CSS component into a gsmcss React component. Use the `gsmcss/dist/gsmcss.bundle.css` import and follow the `g-` utility pattern for all margins and paddings."
