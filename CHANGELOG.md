# Changelog

All notable changes to the **gsmcss** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-17

### Added

- **gsmcss Core Framework Implementation:** Utility-first CSS structure with built-in component logic.
- **Laravel 13 Integration:** Fully compatible with Laravel 13 and PHP 8.4.
- **Livewire 3.7+ Support:** Interactive components powered by Livewire.
- **Custom Tailwind Theme:** Specialized gsmcss colors, shadows, and radii.
- **Component Library:** Initial set of high-quality components:
  - `Button` (Primary, Secondary, Outline, Ghost, Danger, Success)
  - `Card` (Title, Subtitle, Slot, Footer)
  - `Badge` (Multiple variants and rounded options)
  - `Input` (Label, Error support, Disabled state)
- **Built-in Auth System:** Integrated Laravel Breeze for robust authentication.
- **Landing Page:** Modern, high-performance welcome screen.
- **Documentation System:** Interactive documentation section with component previews.
- **User Dashboard:** Comprehensive dashboard for account and project management.
- **Admin Dashboard:** System-wide overview with user management and statistics.
- **Checkout Flow:** Premium feature upgrade system with simulated payment flow.
- **Vite Integration:** Fast asset bundling and hot-reloading.

### Optimized

- **Clean and DRY Code:** Focused on developer adoptability and maintainability.
- **Creative & Modern UI:** Designed for world-class user experiences.
